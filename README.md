# AR Roadster Game

Godot 4.3 ဖြင့်ပြုလုပ်ထားသော Android 3D ကားမောင်းဂိမ်း prototype ဖြစ်သည်။ Project တွင် Unity license secret မလိုပါ။

## ကစားနည်း
- မျက်နှာပြင်ကို ထိပြီးဖိထားလျှင် ကားမောင်းမည်။
- ဖိထားသည့်လက်ချောင်းကို ဘယ်/ညာရွှေ့၍ ကွေ့ပါ။
- ကွန်ပျူတာတွင် ဘယ်/ညာ arrow key သုံးနိုင်သည်။

## APK ရယူနည်း
1. GitHub ရှိ **Actions** ကိုဖွင့်ပါ။
2. **Android APK (Godot)** workflow ကိုရွေးပြီး **Run workflow** နှိပ်ပါ။
3. Build အောင်မြင်သည့် run ကိုဖွင့်ပါ။
4. **Artifacts → AR-Roadster-APK** ကို download လုပ်ပြီး ZIP ဖြည်ပါ။
5. ရလာသော APK ကို Android ဖုန်းတွင် install လုပ်ပါ။

`UNITY_LICENSE` secret မလိုပါ။

## AR အခြေအနေ
ဤ project သည် 3D ကားမောင်းဂိမ်းဖြစ်သည်။ ဖုန်းကင်မရာနောက်ခံနှင့် AR plane tracking ကို မထည့်ရသေးပါ။
